## 4. 🔧 Backend design — `GET /catalog/bestsellers`

The existing `catalog.service.getCategories()` already walks each category's active,
non-hidden products and takes **one** image. We add a sibling that takes **up to four**
(egg-excluded) — additive, **no change to `getCategories` or its tests**.

> **Per `apps/api/CLAUDE.md`: pull Prisma v5 docs via Context7 before writing this query.**

**New service fn** — `catalog.service.ts`:
```ts
// Up to 4 in-stock product images per category (the Bestsellers cluster), shop
// identity irrelevant, aggregated by category NAME across shops, eggs excluded,
// NO counts. Categories with zero usable images are dropped.
const EGG_RE = /egg|अंडा|अण्डा|anda/i;            // exclude egg products

async function getBestsellers(limit = 9) {
  const cats = await prisma.category.findMany({
    where:   { isActive: true, shop: { isActive: true } },
    orderBy: { sortOrder: 'asc' },
    select: {
      name: true, sortOrder: true,
      products: {
        where: {
          isActive: true,
          stockStatus: 'available',
          images: { some: {} },
          NOT: { name: { contains: 'egg', mode: 'insensitive' } },  // DB-side egg filter
        },
        orderBy: { sortOrder: 'asc' },
        take: 8,                                  // headroom; dedupe to 4 below
        select: { name: true, images: { orderBy: { sortOrder: 'asc' }, take: 1, select: { url: true } } },
      },
    },
  });

  const byName = new Map<string, { name: string; sortOrder: number; images: string[] }>();
  for (const c of cats) {
    if (EGG_RE.test(c.name)) continue;            // never surface an "Eggs" category
    const urls = c.products
      .filter((p) => !EGG_RE.test(p.name))         // belt-and-suspenders egg filter
      .map((p) => p.images[0]?.url)
      .filter((u): u is string => !!u);
    const e = byName.get(c.name);
    if (e) { for (const u of urls) if (e.images.length < 4 && !e.images.includes(u)) e.images.push(u); }
    else byName.set(c.name, { name: c.name, sortOrder: c.sortOrder, images: [...new Set(urls)].slice(0, 4) });
  }

  return [...byName.values()]
    .filter((c) => c.images.length > 0)
    .sort((a, b) => a.sortOrder - b.sortOrder || a.name.localeCompare(b.name))
    .slice(0, limit)
    .map((c) => ({ name: c.name, images: c.images }));   // ← NO count field
}
```
**Route** — `catalog.routes.ts` (public, beside `/categories`):
```ts
// GET /api/v1/catalog/bestsellers — category cards with up to 4 sample product
// images each (Bestsellers cluster). No counts, eggs excluded.
app.get('/bestsellers', async (_req, reply) => reply.send(await catalogService.getBestsellers()));
```
**Response shape:**
```json

  { "name": "Chips & Namkeen",     "images": ["…","…"] } ]
```

## 6. ✅ Honesty & edge cases
- **< 4 images** in a category → fill remaining quadrants with a themed placeholder
  tile (no count, no "and more").
- **0 images** → category card omitted entirely (don't render an empty cluster).
- **No fabricated numbers** anywhere.
- **Eggs** excluded at the DB query (`NOT name contains egg`) **and** in JS
  (`EGG_RE`) for category names and product names (bilingual: `egg`/`अंडा`/`anda`).
- Public endpoint → **no shop identity, no PII, no price leak** (names + image URLs only).
